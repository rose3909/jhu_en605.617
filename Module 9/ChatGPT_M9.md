# ChatGPT usage

I used OpenAI ChatGPT to assist with this assignment. My programming
experience is primarily in Python, and I did not know how to code in C++ or CUDA C++ well enough to build this application on my own. I needed help with CUDA syntax, memory management, library calls, and translating my ideas into working code.

However, I did not "one-shot" the assignment by giving ChatGPT a single
prompt and accepting whatever it produced. I worked through the problem with ChatGPT iteratively using it as a learning and coding companion. I wanted to use this assignment to experiment with the GPU-accelerated entity resolution problem I proposed for my final project. We discussed the use case, how to structure the application, which libraries would be a good fit, how their outputs should connect, and what tests would show whether the approach worked.

## Code assistance and files

ChatGPT substantially assisted with writing the C++ and CUDA C++ code,
including the cuBLAS and Thrust operations, GPU memory handling, CPU
validation, error checking, and scripts. I could not have coded those pieces independently at this point, but I reviewed the approach, asked follow-up questions when I did not understand something, and evaluated the output rather than treating the generated code as automatically correct.

## My role and next steps

My role was to define the problem, work with ChatGPT to architect the
solution, understand how the components fit together, run and review the code and interpret the results. ChatGPT helped write the code I did not yet know how to write and I want to re-emphasize that it did not replace my responsibility to understand the approach or assess whether it met the assignment goals.
